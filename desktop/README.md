# راهنمای ساخت «خراط‌کد» — نسخهٔ دسکتاپ ویندوز (آفلاین)
## KharraatCode — Windows Desktop Build

این پوشه ابزارهایی است که از همان کد وب برنامه، یک **فایل اجرایی مستقل ویندوز**
(`KharraatCode.exe`) و یک **بستهٔ ZIP کاملاً آفلاین** می‌سازد.

---

## نتیجهٔ نهایی برای کاربر (بدون هیچ نصب و بدون اینترنت)

```
KharraatCode-Windows-Desktop-v1.0.0/
├── KharraatCode.exe          ← دوبار کلیک؛ همین
├── WebView2Loader.dll        ← باید کنار EXE بماند
├── app/
│   └── index.html            ← کل برنامه + همهٔ فونت‌ها در یک فایل (۱٫۳ مگابایت)
├── app.ico                   ← آیکن برنامه (۱۰ اندازه: ۱۶ تا ۲۵۶ پیکسل)
├── app.cfg                   ← تنظیم اندازه/عنوان پنجره
├── README-فارسی.txt
└── sources/                  ← کد منبع (برای توسعهٔ بعدی)
```

* بدون Node.js، بدون نصب، بدون باز شدن مرورگر، بدون درخواست شبکه.
* فونت‌ها **همان فونت‌های اصلی برنامه** و بدون هیچ تغییری هستند:
  `Vazirmatn` (۴۰۰/۵۰۰/۶۰۰/۷۰۰/۸۰۰)، `Lalezar` و `JetBrains Mono` — به‌صورت
  base64 و بایت‌به‌بایت داخل `app/index.html`.
* رابط کاربری با یک موتور نمایش بومی ویندوز (Microsoft Edge WebView2) نمایش
  داده می‌شود؛ همان موتوری که Edge/ویندوز از آن استفاده می‌کند، بنابراین
  Canvas، فونت‌های فارسی، RTL و WebGL (نمای سه‌بعدی) همه درست کار می‌کنند.

## چرا این معماری؟ (مقایسهٔ گزینه‌ها)

| گزینه | حجم | نیاز به نصب | آفلاین | مناسب ویندوز ۱۰/۱۱ |
|---|---|---|---|---|
| **WebView2 + میزبان بومی (انتخاب‌شده)** | ~۲ مگابایت | ندارد | ✔ | ✔ موتور روی خود ویندوز است |
| Electron | ~۸۰–۱۵۰ مگابایت | ندارد | ✔ | ✔ اما حجیم و کند در باز شدن |
| Tauri | ~۵ مگابایت | ندارد | ✔ | ✔ ولی نیاز به Rust/WebView2 |
| فایل HTML تنها | ۱٫۳ مگابایت | ندارد | ✔ | ✘ کاربر باید مرورگر باز کند (خواستهٔ شما نبود) |

میزبان بومی این پروژه (`host/main.cpp`) یک برنامهٔ C++ کوچک (~۶۴۰ کیلوبایت)
است که پنجرهٔ ویندوز می‌سازد و صفحهٔ محلی برنامه را در WebView2 نمایش می‌دهد.

## ویژگی‌هایی که برای «نپریدن صفحه» در نظر گرفته شده

1. **ناوبری مسدود است**: هر تلاش برای رفتن به آدرسی جز صفحهٔ خود برنامه لغو
   می‌شود (`NavigationStarting.put_Cancel(TRUE)`).
   - کشیدن فایل روی پنجره → صفحه عوض نمی‌شود؛ فایل فقط در `_Incoming` کپی می‌شود.
   - کلیک روی لینک بیرونی → با مرورگر پیش‌فرض باز می‌شود، پنجرهٔ برنامه دست‌نخورده.
   - `window.open` / `target=_blank` → پنجرهٔ جدید ساخته نمی‌شود.
2. **کلیدهای مرورگری خاموش‌اند**: `F5`, `Ctrl+R`, `Ctrl+P`, `F12` و منوی
   راست‌کلیک پیش‌فرض غیرفعال‌اند (`AreBrowserAcceleratorKeysEnabled = FALSE`).
3. **بزرگ‌نمایی قفل است**: `Ctrl+چرخ ماوس` یا pinch، چیدمان پنل‌ها را به‌هم
   نمی‌زند؛ بزرگ‌نمایی همیشه روی ۱۰۰٪ نگه داشته می‌شود.
4. **اندازهٔ پنجره ثابت است**: قاب تغییر اندازه و دکمهٔ بزرگ‌نمایی حذف شده‌اند
   (`fixed=1` در `app.cfg`)؛ بنابراین پنل‌ها هرگز از کادر بیرون نمی‌زنند.
5. **تک‌نمونه‌ای**: دوبار کلیک دوباره روی آیکن، پنجرهٔ دوم نمی‌سازد؛ همان
   پنجرهٔ موجود را جلو می‌آورد.
6. **بستن امن**: هنگام بستن، رویداد `kharraatcode-before-close` به صفحه فرستاده
   می‌شود تا وضعیت ذخیره شود (حداکثر ۰٫۴ ثانیه صبر، بدون معطلی).
7. **کش نسخه‌های قدیمی پاک می‌شود** (`_UserData/.appversion`) اما
   **پروژه‌ها و تنظیمات کاربر حفظ می‌شوند**.
8. **ذخیرهٔ خروجی مشخص است**: جی‌کد/DXF/پروژه در `Documents\KharraatCode`
   ذخیره می‌شود (نه در پوشهٔ موقت) و بار اول همان پوشه باز می‌شود.
9. **بدون پنجرهٔ سیاه کنسول**: زیرسیستم EXE از نوع `WINDOWS` است.
10. **آیکن درست در همه‌جا**: آیکن در منابع EXE (ID ۱) و روی کلاس پنجره
    (`hIcon`/`hIconSm`) تنظیم شده است؛ نتیجه: نمایش صحیح در Explorer،
    نوار وظیفه، Alt+Tab، Start و نوار عنوان.

## ساخت مجدد (فقط برای توسعه‌دهنده)

پیش‌نیازها:

```bash
# ۱) بسته‌های وب
npm install --legacy-peer-deps

# ۲) کامپایلر ویندوز (zig) و Pillow
pip install ziglang pillow
```

ساخت:

```bash
python3 desktop/tools/build-windows.py \
    --app-dir "خراط_کد-—-شبیه_ساز-و-تولید-جی_کد-خراطی-cnc (2)" \
    --out desktop/release
```

خروجی:

```
desktop/release/KharraatCode-Windows-Desktop-v1.0.0.zip
desktop/release/KharraatCode-Windows-Desktop-v1.0.0.zip.sha256
```

مراحل داخلی:

| فایل | کار |
|---|---|
| `tools/bundle-html.mjs` | همهٔ CSS/JS/فونت‌ها را در یک `index.html` خودبسنده ادغام می‌کند و اسکریپت را به IIFE تبدیل می‌کند (سازگار با همهٔ نسخه‌های WebView2) |
| `tools/make-icons.py` | آیکن `.ico` چند‌اندازه‌ای + پیش‌نمایش PNG می‌سازد |
| `host/main.cpp` | میزبان بومی ویندوز (WebView2 + پنجرهٔ ثابت + قفل ناوبری) |
| `host/app.rc` | آیکن، اطلاعات نسخهٔ فایل و مانیفست (DPI آگاه، پشتیبانی ویندوز ۱۰/۱۱) |
| `tools/build-windows.py` | کل فرآیند را اجرا و ZIP را می‌سازد + بررسی می‌کند EXE حتماً زیرسیستم گرافیکی باشد |

## عیب‌یابی (سمت کاربر)

| نشانه | علت | راه‌حل |
|---|---|---|
| پیام «موتور نمایش پیدا نشد» | WebView2 Runtime روی آن ویندوز نیست | نصب یک‌بارهٔ WebView2 Runtime از سایت مایکروسافت |
| پیام «پوشهٔ app پیدا نشد» | ZIP بدون استخراج اجرا شده | راست‌کلیک → Extract All، بعد اجرا |
| SmartScreen هشدار می‌دهد | فایل امضای تجاری ندارد | More info → Run anyway (یا Unblock از Properties) |
| هیچ پنجره‌ای باز نمی‌شود | ضدویروس DLL را حذف کرده | `WebView2Loader.dll` را از ZIP برگردانید |
| برای پشتیبانی | — | در `app.cfg` مقدار `log=debug.log` را بگذارید و فایل لاگ را بفرستید |
